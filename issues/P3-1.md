# P3-1 — The README promises "any uncaught exception or PHP error will now …

## Finding / 问题

- EN: The README promises "any uncaught exception or PHP error will now display a beautiful debug page", but `register()` installs only an exception handler and an error handler — there is no `register_shutdown_function`, so E_ERROR/E_PARSE/E_CORE_ERROR and anything before registration are not rendered.
- 中文: README 承诺「任何未捕获异常或 PHP 错误都会显示调试页」，但 register() 只装了异常处理器与错误处理器，没有 register_shutdown_function，因此 E_ERROR/E_PARSE/E_CORE_ERROR 以及注册之前发生的错误都不会被渲染。
- Where / 位置: `README:50,199 vs src/DebugPage.php:39-63`
- Verification / 验证: static / 仅静态推断
