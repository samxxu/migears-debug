# G2 — Strict flags: `phpunit.xml.dist` currently sets `failOnWarning`, …

## Finding / 问题

- EN: Strict flags: `phpunit.xml.dist` currently sets `failOnWarning`, `failOnNotice`, `failOnDeprecation`, `failOnRisky`. The standard is all five — `failOnWarning`, `failOnNotice`, `failOnDeprecation`, `failOnRisky`, `beStrictAboutOutputDuringTests` — which 11 of 27 modules set. Missing here: `beStrictAboutOutputDuringTests`. Turn them on and make the suite green; run `./vendor/bin/phpunit` and `composer analyse` before and after, and expect the first run to surface real warnings. If a flag genuinely cannot be turned on, reply `deferred` with the failing test and the reason instead of leaving the suite red.
